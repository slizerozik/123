# Demon Cow (NeoForge 1.21.1)

Мод добавляет **Коровий колокольчик**. ПКМ — в ~48 блоках впереди начинается ритуал (взрывы, молнии, красные лучи с неба), открывается гигантский портал, и из него вылетает **Демоническая корова**.

Пока корову не трогают, она спокойно висит перед порталом. После первого удара встаёт на задние ноги и по очереди бьёт лазерами из глаз, молочным лучом и ударом по земле. 600 HP, босс-бар; после смерти портал закрывается.

- Получить: вкладки «Инструменты» / «Оружие» в креативе, `/give @s demoncow:cow_bell` или крафт (блок редстоуна сверху, золотой слиток — колокол — золотой слиток, сырая говядина снизу).
- Разрушение блоков подчиняется правилу `mobGriefing`.

## Сборка

Нужна Java 21: `./gradlew build`, готовый файл — `build/libs/demoncow-1.0.0.jar`.
Текстуры генерируются скриптом `tools/gen_textures.py` (pillow + numpy).
